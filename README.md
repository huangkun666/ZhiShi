# 织世

织世是一款在安卓手机上运行的世界模拟与角色扮演应用。你可以导入世界书、选择角色开局，在聊天中使用预设和世界书设计的状态栏。世界、角色和存档保存在手机上。

## 安装

大多数近年的安卓手机可选择 ARM64 版。32 位 ARM、x86_64 设备或不确定处理器架构时，可选择通用版。最低支持 Android 8.0。[下载 ARM64 版](https://github.com/huangkun666/ZhiShi/releases/latest/download/World-RP-arm64-v8a.apk) · [下载通用版](https://github.com/huangkun666/ZhiShi/releases/latest/download/World-RP.apk)

首次打开后，在「应用设置 → 模型与用途」配置自己的模型，再到世界库导入世界文件。已安装原「世界模拟 RP」的用户可以直接覆盖安装并继续游玩。

## 更新

0.1.3 起内置本仓库的更新地址。应用会在完整启动时检查新版，也可以打开「应用设置 → 软件更新」手动检查。程序资源下载并验签成功后，点「关闭应用以更新」，再从桌面打开。需要更新 Android 原生组件时，应用会打开对应安装包。[发行记录](https://github.com/huangkun666/ZhiShi/releases)
